
## ❯ /security — reportar una vulnerabilidad

¿Has encontrado un fallo en alguna de nuestras apps? Gracias por avisar antes de hacerlo público.

- Si el repositorio afectado tiene activada la opción, usa la pestaña **Security → Report a vulnerability** para enviar un aviso privado.
- Si no, contacta a través de la [web](https://www.unfantasmaenelsistema.com) y no publiques los detalles hasta que se haya podido corregir.
