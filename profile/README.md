## 🤝 Nuestra promesa

- **Código abierto y auditable.** El código gratuito se publica aquí para que cualquiera pueda revisarlo.
- **Sin telemetría oculta.** No recopilamos datos a escondidas. Si una app usa un servicio externo (por ejemplo, una API de IA con tu propia clave), se indica en su README.
- **Uso responsable y ético.** Estas herramientas existen para aprender y defender, no para dañar.
- **Máquinas vulnerables solo en entornos propios.** Los laboratorios y escenarios intencionadamente vulnerables son solo para practicar en tus propios entornos de prueba, nunca contra sistemas ajenos.

## 🔐 Reportar un problema de seguridad

¿Has encontrado una vulnerabilidad en alguna de nuestras apps? Gracias por avisar antes de hacerlo público.

- Si el repositorio afectado tiene activada la opción, usa la pestaña **Security** → **Report a vulnerability** para enviar un aviso privado.
- Si no, ponte en contacto a través de la [web](https://www.unfantasmaenelsistema.com) y no publiques los detalles hasta que se haya podido corregir.
